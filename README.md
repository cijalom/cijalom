## 🚀 Projects

### 🥕 Treasure Bunny — [Link](https://github.com/cijalom/treasure-bunny)
A cross-platform desktop platformer where you play as a carrot-hunting bunny.

Treasure Bunny is a game where you play as a rabbit hopping around obstacles for a chest full of carrots! The game features an algorithm that generates levels by taking a hard-coded string and mapping different characters to different objects at different positions based off of their index.

**Stack:** HTML · CSS · JavaScript · [Phaser](https://phaser.io/) · [Electron](https://www.electronjs.org/)

---

### 🌸 Imprai Website — [Link](https://cijalom.github.io/imprai-website)
A modern desktop-oriented static website for a conceptual campaign about regulating AI infrastructure.

The website features several custom components created with React and Tailwind in order to create a sleek and modern web experience that is uniform across the entire website while still maintaining accessibility.

**Stack:** HTML · CSS · JavaScript · [Vite](https://vitejs.dev/) · [React](https://react.dev/) · [Tailwind CSS](https://tailwindcss.com/)
